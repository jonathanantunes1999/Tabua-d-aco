# Imagens do site — Tábua d'Aço

O site usa estes ficheiros. Enquanto não existirem, as fotos mostram um
*placeholder* elegante (gradiente verde + legenda) — o site nunca fica partido.
Basta colocar aqui os ficheiros com **exatamente estes nomes** para as fotos reais aparecerem.

| Ficheiro | Onde aparece | Sugestão |
|---|---|---|
| `logo-tabua-daco.png` | **Header** (logótipo) | O **logo do restaurante**. Exportar em **PNG com fundo transparente** (ou SVG). Altura útil ~48px, mas envia em alta resolução. Sem ele, aparece o wordmark "tábua.d'aço" em texto. |
| `hero-tabuaco.jpg` | **Header / hero** (fundo grande) | A **vista aérea da vila de Tabuaço** no Douro (a 2ª imagem que enviaste). Ideal ≥ 2000px de largura, horizontal. |
| `porta-tabuaco.jpg` | Secção "O Restaurante" | Fachada / porta tradicional ou o espaço do restaurante (formato vertical 4:5). |
| `galeria-1.jpg` · `galeria-2.jpg` · `galeria-3.jpg` | Faixa de 3 fotos | Pratos / momentos à mesa. A do meio é quadrada. |
| `prato-bacalhau.jpg` | Especialidade 01 | Bacalhau com broa na telha (4:3). |
| `prato-cabrito.jpg` | Especialidade 02 | Cabrito assado com arroz de forno (4:3). |
| `prato-javali.jpg` | Especialidade 03 | Costeletinhas de javali / veado (4:3). |
| `chef-thomas-egger.jpg` | Secção "O Chef" | Retrato do Chef Thomas Egger (vertical 3:4). |

**Otimização:** exportar como JPG/WebP comprimido (qualidade ~80). O hero em ≥ 2000px;
as restantes ~1200–1600px chegam. Mantém os nomes exatos — o `index.html` refere-os diretamente.
